# User Management Project

این یک پروژه‌ی ساده‌ی مدیریت کاربران است که با استفاده از JavaScript و Firebase ساخته شده.

## 📋 امکانات پروژه
- اضافه کردن کاربران
- ویرایش اطلاعات کاربران
- حذف کاربران
- نمایش لیست کاربران به صورت زنده از دیتابیس firebase

## 🛠 تکنولوژی‌های استفاده شده
- HTML
- CSS
- JavaScript (Vanilla)
- Firebase Realtime Database
